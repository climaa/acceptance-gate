# The layering rule

`packages/ui/src` is organized into {TIERS.length} tiers, innermost first:

<ol>
  {TIERS.map((tier) => (
    <li key={tier}>
      <code>{tier}</code>
    </li>
  ))}
</ol>

A component may import from its own tier and from any tier before it in that list — atoms,
then molecules, then organisms, then templates. The reverse is the violation the rule exists
to forbid: a molecule can compose atoms, but an atom can never import a molecule, and a
template can reach down through every tier below it. Composition within a tier is allowed —
a molecule may hold smaller molecules — since that is how the component inventory is built.

## Why this is enforced, not just documented

[`eslint-plugin-boundaries`](https://github.com/javierbrea/eslint-plugin-boundaries), configured
in `packages/ui/eslint.config.mjs`, turns the rule above into a lint error: importing a later
tier from an earlier one fails `pnpm lint`. The element list that rule is built from —
one entry per tier, plus one for each tier's barrel (`src/<tier>/index.ts`) — is generated by
mapping over the very `TIERS` array rendered above, imported from
`@gate/visual-diff/policy`. There is only one array naming the tiers in this repo: the same
one drives this list, the boundaries rule, and the visual-diff capture matrix (see the
[Diff Policy](?path=/docs/docs-diff-policy--docs) page), so a tier added to the design system
extends all three without an edit anywhere else.

## Where else the same list drives the matrix

The Diff Policy docs page renders the visual-diff capture matrix from the same `TIERS` array —
tier and viewport are two axes of one `Mode`, and `tierOf()` places a captured story by walking
the same list. A tier is one definition, consumed in three places.

## The one exception the rule allows

A tier's barrel is allowed to re-export its own tier — that is what a barrel is for — but that
allowance belongs to the barrel itself, not to a component that imports through it. Reaching a
sibling component via the tier barrel instead of a direct import is still a violation: the
barrel may look inward, but nothing may use it to look sideways.
