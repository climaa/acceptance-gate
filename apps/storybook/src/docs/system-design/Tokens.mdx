# Tokens

`@gate/ui/tokens.css` is the single source of truth for colour and type — every value below
is read out of that file (via `?raw`), not typed a second time here. Editing a token in the
sheet changes what renders on this page; this page cannot drift from it because it has no
values of its own to drift.

export const roles = colorRoles(tokensRaw);
export const sizes = fontSizeSteps(tokensRaw);

## Colour roles

Every `--color-*` role, resolved to a literal in both themes. Components never reference a
raw `--c-*` step directly — tokens.css's own contract requires every one of those to be
consumed by a role — so the roles below are also the complete palette a component author can
reach.

### Light

<ColorPalette>
  {roles.map((role) => (
    <ColorItem
      key={role.name}
      title={role.name}
      subtitle={role.light}
      colors={[role.light]}
    />
  ))}
</ColorPalette>

### Dark

<ColorPalette>
  {roles.map((role) => (
    <ColorItem
      key={role.name}
      title={role.name}
      subtitle={role.dark}
      colors={[role.dark]}
    />
  ))}
</ColorPalette>

## Type scale

The `--text-*` scale is theme-invariant — typography carries no colour, so there is one scale
rather than one per theme (tokens.css states this explicitly: only the `--color-*` roles remap
under `[data-theme='dark']`). Sample text below renders at every step, ascending.

<Typeset fontSizes={sizes.map((step) => step.value)} sampleText="Aa Bb Cc 0123" />

{sizes.map((step) => (

  <p key={step.name}>
    <code>{step.name}</code>: {step.value}
  </p>
))}
