# The diff policy

`@gate/visual-diff/policy` names the capture matrix — every (tier, viewport, theme) cell a
story can be captured under. This page reads `TIERS`, and the eslint boundaries rule described on the
[Layering Rule](?path=/docs/docs-atomic-design-layering-rule--docs) page reads the same list without
`screens`, the console's own pages, as `UI_TIERS`; the
capture CLI, the comparison and the CI job that read this matrix to actually run the diff are
described on the [Visual Diff Workflow](?path=/docs/docs-qa-visual-diff-workflow--docs) page.
What follows describes the matrix itself, as it exists in the repo today.

## Why atoms and molecules are desktop-only

<ul>
  {Object.entries(TIER_VIEWPORTS).map(([tier, viewports]) => (
    <li key={tier}>
      <code>{tier}</code>: {viewports.join(', ')}
    </li>
  ))}
</ul>

An atom or a molecule does not change shape between viewports — nothing in either tier is
built to reflow with the page. Capturing them at mobile as well would double their baseline
count while catching nothing a desktop capture would not already show. Organisms and
templates compose the tiers below them into layouts that do respond to viewport width, so
both get the full `desktop` + `mobile` pair.

## Story-level tags

Three tags a story's own `tags: [...]` array can carry, named here from the module that defines
them rather than retyped as string literals:

export const storyTags = [
  {
    tag: SKIP_TAG,
    description:
      "marks a story that cannot be captured deterministically, excluding it from its tier's usual cells.",
  },
  {
    tag: ALL_VIEWPORTS_TAG,
    description: (
      <>
        the per-story override of <code>TIER_VIEWPORTS</code>: captures a story at every
        viewport in <code>VIEWPORTS</code>, whatever its tier's default is. For the one
        component that does reflow with width without the rest of its tier needing the
        same promotion.
      </>
    ),
  },
  {
    tag: LOCALES_TAG,
    description: (
      <>
        lists a story for the locale axis: it is captured once per entry in{' '}
        <code>LOCALES</code> ({LOCALES.join(', ')} here), and its variant key gains the
        locale between the theme and the story id. Nothing here is listed — this
        repository ships English only — so every key keeps the four-part shape. A child
        with translated UI lists its own stories and locales.
      </>
    ),
  },
];

    </li>
  ))}
</ul>
